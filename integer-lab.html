How the methods work

Frequency baseline
Predicts the most frequent integer in the history. Ties go to the smaller integer.
Validated first-order transition
Learns which value usually follows each observed value, then checks the rule on held-out history. It abstains if validation or the forecast path lacks support.
Verified cycle
Checks for a repeating cycle of whole integers. It continues the cycle when held-out history confirms it.
