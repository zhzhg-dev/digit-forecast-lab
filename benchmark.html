Independent synthetic benchmark

Each synthetic process uses independently initialized sequences. Each sequence contributes one forecast, with the same history and target for every method.

Method Accuracy Log loss vs. frequency (pp) 95% paired interval (pp)

Each paired interval uses the mean difference in per-sequence hits versus smoothed frequency, plus or minus 1.96 standard errors. Intervals apply to each condition separately.

The Transformer was pretrained on separate synthetic data and reads at most the last 32 digits. The statistical methods estimate probabilities from each test history. Scores describe performance on these synthetic settings.

Reproduce the benchmark from the repository with npm run benchmark -- --holdout
